# mvp1 — веб-конференции на Go

Этот репозиторий предназначен для разработки mvp1: публикации разрешённых
серверных приложений Falkon (основной), Firefox (резервный) и terminal через WebRTC для Chrome и совместимых
браузеров. Серверная логика — Go. Одновременно не больше двух независимых
пользователей, до двух активных приложений у каждого (до четырёх сеансов).
В будущем — до трёх приложений на пользователя в разных вкладках и переход
к отдельному API gateway. Приняты SQLite, роли, Pion, coturn, Go gateway
и изолированное Linux-окружение; SFU в пилоте не нужен.
Серверная платформа — Linux; клиент работает через браузер на Linux, Windows
и macOS. Приоритет MVP — полный клиентский путь и удобство работы приложений.
В будущем возможен отдельный Electron-клиент; в текущий MVP он не включён.
Ввод и документы для локальной печати передаются через DataChannel.
Нужны лёгкая БД пользователей, несколько ролей, администрирование доступа и TURN.
Требования и предложенные решения разделены в [архитектуре](docs/architecture.md).
Каталоги `testing/` и `deploy/` предназначены для тестового и рабочего запуска
соответственно. Не смешивай их БД, секреты, профили и артефакты.
Общайся с пользователем на русском языке.

## Работа с проектом

- Сначала изучи существующий код и принятые решения. Предложенная структура
  из skill не требует перемещать уже работающие компоненты.
- Не представляй предполагаемые функции и выбранные по умолчанию технологии
  как требования пользователя. Записывай существенные допущения в документации.
- Создавай код и каталоги по мере реализации, без пустых заготовок на будущее.
- Версии Go и библиотек выбирай по совместимости и официальной документации,
  фиксируй в `go.mod` и `go.sum`. Не используй непроверенные номера версий.
- Выполняй проверки, соответствующие изменению; в результате указывай, что
  проверено, и отдельно — что осталось непроверенным.

Пароли хранятся только как Argon2id-хеши с солью (ADR-011). Срок входа —
один час без продления активностью. Открытое хранение отменено.
