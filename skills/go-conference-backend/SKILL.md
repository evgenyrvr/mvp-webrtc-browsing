# Go-бэкенд конференций

Прочитай `go.mod`, текущие обработчики и архитектуру, если они существуют.
Сохраняй выбранные библиотеки; для нового HTTP API начни с `net/http`, если
требования не дают конкретной причины выбрать другой подход.

## Комнаты и доступ

- Опиши переходы создания, входа, выхода и закрытия комнаты. Обновление лимита
  участников и регистрация участника должны быть атомарными.
- Отделяй идентификатор участника от конкретного соединения. Старый обработчик
  отключения не должен удалять новую сессию после переподключения.
- Проверяй доступ к комнате и адресату на сервере. Непредсказуемый ID комнаты
  сам по себе не заменяет проверку доступа; для гостевого входа явно определи
  семантику приглашения и срок его действия.
- Валидируй размер тела, обязательные поля и допустимые операции. Опиши
  единый формат ошибок, HTTP-статусы и повторяемость запросов в контракте API.

## Конкурентность и жизненный цикл

- Выбери одного владельца состояния либо синхронизацию. Не выполняй сетевую
  запись, callback или долгий запрос к БД под блокировкой реестра комнат.
- У каждой goroutine должны быть владелец и путь завершения. Передавай
  `context.Context` в операции с дедлайном; освобождай таймеры и подписки.
- Ограничивай очереди событий. Заранее определи поведение при медленном клиенте,
  чтобы одна сессия не блокировала комнату и не накапливала память без границ.
- Удаление участника и закрытие ресурсов делай идемпотентными. При остановке
  отдельно закрывай WebSocket и медиа: остановка HTTP-сервера не заменяет
  управление долгоживущими соединениями.

## Хранение и готовность

Для БД используй параметры запросов, ограничения целостности и миграции;
транзакции определяй по инвариантам, а не по границам HTTP-обработчика.
Интерфейсы вводи на границах реальных зависимостей.

Проверь изменённые пакеты и сценарии доступа/конкурентного входа. Для изменений
общего состояния используй race detector. Не выводи токены и полные SDP в логи.

Официальные материалы для работы с отменой и гонками:
[context](https://go.dev/blog/context),
[race detector](https://go.dev/doc/articles/race_detector).
