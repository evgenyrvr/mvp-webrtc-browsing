# ADR-007: виртуальный IPP-принтер на Go

Статус: принято пользователем 19 сентября 2026 года.

В каждом изолированном окружении приложения работает виртуальный IPP-принтер,
реализованный на Go. Отдельный демон CUPS не используется. Firefox обращается
к принтеру через системную клиентскую библиотеку и IPP на loopback внутри
контейнера. Принтер принимает только PDF; загрузка документов по URL исключена.

PDF передаётся владельцу сеанса через надёжный упорядоченный DataChannel `print`.
Клиент проверяет размер и SHA-256, затем предлагает открыть PDF для печати
через локальный диалог браузера. Автоматическая печать без действия пользователя
не выполняется. Подтверждение доставки означает получение PDF, а не физическую
печать. Переподключение не должно приводить к автоматической повторной печати.

Право `can_print` проверяется при приёме задания и перед каждой порцией передачи.
Очередь принадлежит одному worker: до двух PDF по 25 MiB, срок хранения 10 минут.
Документы хранятся в памяти worker, удаляются при отзыве права или остановке.
Незавершённая доставка может повториться после переподключения с тем же ID.
Клиент освобождает Blob URL при закрытии сеанса и отзыве права.

Доступ к физическим принтерам Linux, Windows и macOS обеспечивает клиентская ОС.
Прямое управление устройствами, драйверы и Electron-клиент находятся вне MVP.
