# ADR-005: поведение первого рабочего прототипа

Статус: принято пользователем 2026-09-17.

Для первого прототипа подтверждены:

- одноразовые профили Firefox; завершение сеанса удаляет профиль;
- terminal запускает shell только внутри изолированного окружения;
- печать: PDF передаётся по DataChannel и открывается для локального диалога;
- звук, общий буфер обмена и общий файловый обмен не входят в прототип.

Краткое переподключение сохраняет ещё живое приложение согласно согласованной
модели сеансов; долгосрочное сохранение профилей не включается.
Эти решения дополняют [ADR-004](004-client-platforms-and-mvp-experience.md).
Сетевые назначения приложений и адрес TURN уточняются перед сетевым запуском.
