# ADR-010 — Максимальная длительность приложения в пилоте

Дата: 2026-10-07. Статус: принято пользователем.

Каждый сеанс Falkon, Firefox и terminal автоматически завершается через
30 минут с момента создания запуска. Это ограничение времени жизни, не таймаут
бездействия: ввод, печать, переподключение и смена вкладки не продлевают срок.
Пользователь может самостоятельно запустить новое приложение после завершения.
Несохранённые данные одноразового окружения при закрытии теряются.

Gateway проверяет created_at при периодической сверке (каждые 5 секунд),
переводит просроченный сеанс в stopping и освобождает слот только после успешной
остановки runtime. Неудачная остановка повторяется. Worker дополнительно имеет
собственный 30-минутный дедлайн процесса; Kubernetes Pod — activeDeadlineSeconds
1800. Задержки планирования/очистки могут отложить отображение closed в интерфейсе.

Перезапуск gateway по действующей политике завершает активные приложения;
срок существующих сеансов не сбрасывается. Настройка распространяется на
всех пользователей, включая администратора, и на Docker/Kubernetes.
