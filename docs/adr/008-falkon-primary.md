# ADR-008: Falkon — основной опубликованный браузер

Статус: принято пользователем 2026-10-07; Docker-интеграция проверена.

Основной браузер MVP — Falkon, отдельное приложение с ID `falkon` и шаблоном
`falkon`. Firefox сохраняется как резервный вариант и для старых сеансов.
Миграция SQLite добавляет Falkon и копирует существующие права на Firefox,
включая launch/control/print и состояние enabled. Пользователи и история
сеансов сохраняются. Каталог показывает Falkon перед Firefox.

Falkon, QtWebEngine, клиентские библиотеки печати, шрифты, Xvfb, Openbox,
FFmpeg и Go worker устанавливаются при сборке контейнерного образа.
На узлах Ubuntu браузер и его библиотеки отдельно устанавливать не требуется.
Профиль остаётся одноразовым, приложения работают как UID 1000.
Встроенная песочница QtWebEngine не отключается автоматически при ошибке запуска.

Экономия RAM/CPU и ускорение старта пока не подтверждены сравнительным тестом.
Критерии приёмки: запуск в ограниченном контейнере, видео, ввод, профиль,
Go IPP/PDF и четыре независимых сеанса. Переход к Kubernetes требует отдельной
проверки sandbox на узлах и управляющего runtime.
